about

LRM lets developers open a repo on their machines, auto-discover teammates over the network, and collaborate on code in real time — with zero central authority, zero lag (state streams directly peer-to-peer), and absolute privacy (everything is end-to-end encrypted and content-addressed). 

Developer A  ◄─── direct P2P (LAN mdns / WAN Port Key) ───►  Developer B
   .lrm/objects (SHA-256 CAS)         encrypted mux streams        .lrm/objects (SHA-256 CAS)
  • No remotes. Every peer is a full remote; discovery replaces URLs.
  • No force-push. History is a content-addressed DAG; concurrent tips coexist as branches until merged.
  • No staging ritual. An always-on virtual index tracks every file; commit just versions the Merkle root.
  • Pure Go stdlib. One static binary, no dependencies, close to OS primitives.

60-second quickstart

# Build
make build          # produces ./lrm (pure Go stdlib, no dependencies)

# Alice starts a project
mkdir demo && cd demo
lrm init --user alice
echo "hello LRM" > hello.txt
lrm commit -m "first commit"

# Same Wi-Fi: Bob finds Alice automatically
lrm peers                    # → alice @ 192.168.1.5:8443
lrm daemon                   # background real-time sync (both sides)

# Different Wi-Fi / across the globe: Alice shares a Port Key
lrm share
# → lrm1_AQQiUwEBIPvCWoLq6VlKc14ZBsidRqO_hvaGtYYQZa8mLBVepV0yrw

# Bob pastes it — router ports auto-open, STUN finds the
# public IP, and a verified encrypted channel syncs history:
lrm join lrm1_AQQiUwEBIPvCWoLq6VlKc14ZBsidRqO_hvaGtYYQZa8mLBVepV0yrw

roadmap

  • Message envelopes + version negotiation on every wire message
  • UDP hole punching and paired-peer relay for CGNAT reachability
  • STUN/ICE UDP hole punching for symmetric NATs
  • DHT peer routing (Kademlia) for global discovery without key exchange
  • Delta-compressed object transfer for huge binaries
  • FUSE workdir overlay for instant multi-GB checkouts
  • lrm web — local DAG visualizer
